## 「为什么必然不及格」级问题（§7 要求至少 1 条）

**C1 是不及格项**：PRD §FR-1 承诺「机器防跳阶段」（"这是 BMAD 先 approve 再执行的 TT 代码级等价物"），但实现把防跳做成了 **exit code 形同虚设的旁路系统**——唯一的机验子命令 `--prereq-check` 在整个仓库 0 处被调用（grep 实证：仅 tt-journey.mjs 自身与文档提及），而真正改状态的写入口 `--update` 连一行前置判断都没有。也就是说：这个系统防跳的强度 = 「agent 心情好就遵守」。竞品（Claude Code task tools、BMAD sprint-status 单源同步）都不依赖被编排者的自觉。**一个把「防跳」写进 PRD 验收、却在写路径上零强制的实现，按其自身标准就是不及格。**
