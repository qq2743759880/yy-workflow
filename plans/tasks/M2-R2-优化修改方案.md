## §2 C-31（P1）：gate 产物模板加「阶段机验」字段 + 机验

### 2.1 模板改动（6 个文件）

`templates/owner-review/*.md`（5 份）+ `templates/completion-report.md`，头部统一加字段：

```
阶段机验: [ ] `node scripts/tt-journey.mjs --prereq-check --step <n>` exit 0（注入前必跑，回填输出一行）
```

- agent 注入阶段 prompt 时必须实跑并回填（done + exit 码）；gate 产物落盘时字段随之留痕。
- `/yy N` 未跑 → 字段空 → 验收核对 FAIL，不接受「我自觉跑过了」。

### 2.2 机验链

1. `validate-structure.mjs`：断言 6 模板全部含「阶段机验」字段，缺失 FAIL 具名文件。
2. `review-gate.mjs` 验收路径：gate 产物含 owner-review 结构时，核对「阶段机验」已回填（非空 + 含 `--step` 与 exit 0），缺失/未回填 → 验收核对项 FAIL。
3. 回归：regression-all 增用例——删字段 FAIL / 空字段 FAIL / 回填 PASS 三态。
