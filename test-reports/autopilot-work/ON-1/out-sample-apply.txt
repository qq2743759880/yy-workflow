[executor-setup] 非 TTY 环境，各字段按默认值填写（可后改；--apply 实际写入）。

你将写入这些字段（落到 orchestrator.config.yaml；可后改，--apply 才真写）：
  orchestrator.subagentSource = "session"（本次新填）
      默认 session · 子 agent 由本编排会话内建调度，无需额外 CLI（零依赖、最低门槛）。 · 后续可在 orchestrator.config.yaml 直接改写；改后无需重装。
  orchestrator.delegationMode = "self-dispatch"（本次新填）
      默认 self-dispatch · 编排者自己派单给子 agent，简单场景不经过用户交接；复杂决策再切 handoff-prompt。 · 切 handoff-prompt 后派单会变成“给用户一段交接 Prompt”，可后改。
  critique.sources = "none"（本次新填）
      默认 none · 批判源清单尚无既有清单（CR-1 未落），先空（none）；确认后再逐项填知识库/搜索/标准文档路径。 · 可追加多项；none 表示不依赖外部批判源。
  report.style = "plain"（本次新填）
      默认 plain · 验收报告先按大白话（plain）交付，后续按需切 technical 或两者并存。 · 风格只影响输出措辞，不影响事实结论。
  blindwalk.enabled = true（本次新填）
      默认 true · 阶段盲测是终验纪律（SB-1），默认开启防学习效应；验收通过可关。 · 关闭 = 取消盲测开关，终验纪律降级，需 Owner 确认。
  mcp.tools = []（本次新填）
      默认  · MCP server（chrome-devtools-mcp 等）按需接入，默认不接（零依赖）。 · 填“工具名1,工具名2”后逐项作为列表落盘；可后续增删。
