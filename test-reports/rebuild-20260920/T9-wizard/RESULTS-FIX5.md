1. **保留数入文件头命名常量**：新增 `const RETAIN_RUNS = 5;`（`HERE` 定义之前），注释说明策略——跑完不清理本轮（结果原样留证）+ 只修剪历史 run-* 目录、保留最近 RETAIN_RUNS 个防爆盘。原 IIFE 内联字面量 `5` 移除。
2. **修剪逻辑稳健化**（原 `fsp.readdir(...).then(...)` fire-and-forget 重写为独立 `async function pruneSandboxes()`，并在 `main()` 收尾 `await`，保证修剪在进程退出前完成）：
   - 只匹配 `run-` 前缀**目录**且形态合规（`/^run-.+-\d+$/`，即 `run-<stamp>-<pid>`：中段戳 + 末段数字）；`withFileTypes` 判 `isDirectory()`，run- 前缀的普通文件与非 run-* 前缀的目录/文件一律不动（留证纪律）。
   - 排序由"名字字典序"改为 **mtime 降序**（stat 失败兜底 mtime=0 + 名字次序），取最新 `RETAIN_RUNS` 个，其余淘汰（`fsp.rm recursive+force`）。
   - 静默降级保持：单目录 rm `.catch(() => {})`；整体 readdir/stat 失败包 `try/catch` 静默吞掉，不影响探针结果与退出码。
3. 文件头沙箱说明注释同步（"跑完不清理本轮 + 仅修剪历史 run-* 保留最近 RETAIN_RUNS 个"）。
