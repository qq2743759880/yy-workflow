## Deliverable A — freeze `C-R1-baseline` BEFORE measuring

R1's freeze order requires the measurement schema to be frozen before the measurements run. Write and hash the schema first; reference that hash in every later result.

The schema must define at minimum these field groups:

1. inventory: asset id, source path, manifest path, body path, source hash, metadata status, body size, resource size, current load status, current route status (exactly 16 in-scope ids; missing or duplicate ids fail the probe);
2. route battery: input, cluster/candidates, result state (MATCHED / NO_MATCH / AMBIGUOUS / INELIGIBLE), margin, abstain reason;
3. cost: metadata startup tokens, body activation p50/p95 tokens, resource overfetch count, cold/warm catalog latency, read count per asset;
4. control: phase bypass, gate fail-open, partial skip, asset receipt completeness, Journey read/write, session collision;
5. OBS: for `OBS-01` and `OBS-02`, exit code, failure segment, blocking-or-not, artifact path, per execution path (standalone CLI, orchestrator, CI).
