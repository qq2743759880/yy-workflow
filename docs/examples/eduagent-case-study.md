# 案例研究：EduAgent 重构（TT 闭环实战示例）

> 来源：tgent v1.0~v1.23 迭代日志（EduAgent 5 天实战，1092 消息）。此处仅保留**可迁移的方法论示例**，项目细节已脱敏。

## 背景

一个多 Agent 平台协作重构项目：opencode 编排 + Trae 后端 + TraeWork/Codex 前端，共享一套 AI-Hub 资产。产出 8+1 个核心界面 HTML 原型 → 用户审核签收 → 组件实现 → 独立实证验收。

## 关键沉淀（可迁移原则）

1. **HTML 原型 gate 防翻车**：先静态 HTML（全交互态 + 内联样式 + 真实数据）→ 用户 APPROVED 才写组件；改动成本低一个量级。
2. **契约先行流水线**：后端域完成即写契约单（含真实 curl 示例）→ 测试 agent 独立核验置"契约已验收" → 解锁前端；契约变更级联失效重验。
3. **跨平台切换返工**：同一 task 不过不原地死磕，切换平台/子 agent 重审重测——换一双眼睛暴露单平台自证自清盲区。
4. **强制批判 + 竞品对标**：每次验收 ≥3 条批判，每条必须带真实竞品实证（URL+日期）；批判结论反哺下一轮任务。
5. **真实数据纪律**：效果图用贴近真实的数量与形态，禁止空数据/MOCK 冒充（曾被用户质疑"只有 12 条？"→ 改取真实数据）。
6. **页面空白排查教训**：外部资源加载阻断、选择器误匹配根元素、图标库闭包 bug、flex 布局在 file:// 协议高度失效 → 最终纯 HTML + 传统 block 布局 + 自包含版本解决；每轮修复后必须**真渲染验证**而非只看代码。

## 失败模式对照（来自实战）

| 现象 | 根因 | 止损（已入 §6.4） |
|------|------|------------------|
| 页面全黑 | 外部资源加载被阻断 + JS 报错中断 | 自包含版本 + 渲染验证 |
| 内容区空白 | 面包屑选择器误匹配 body | 收窄选择器 `.top-bar [data-crumb]` |
| 图标全部失效 | icons.js 闭包传参 bug | 单点根因排查 + jsdom 真机验证 |
| 高度塌陷 | flex 布局在 file:// 协议失效 | 传统 block 布局 + sticky 顶栏 |

## 对本案例的思考

- 案例中"用户改进→重跑 1~3 步"的回跳机制被多次验证有效（文档层→重拆→重规划，已实施产物不回退）。
- 单项目教训在写入 skill 前须抽象为通用原则（跨任务证据包），避免把特例当规则。
