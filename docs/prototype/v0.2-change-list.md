## v0.2 新增三项（多会话场景，2026-09-10 编排者会话确认）

### V2-1 会话标签
- 浮窗标题栏或顶部显示当前数据来源：`<workspace 目录名> · <sessionId | 默认>`
- 数据源：加载 journey.json 时的文件路径（本地展示，不发网络请求）
- 约束：只提示不注入边界不变；无新依赖

### V2-2 会话切换列表
- 入口框旁加下拉/列表：扫描常用项目目录（v0.2 原型用演示目录数组，真机版由用户配置一次）
- 每行显示：`项目名 · session · 当前阶段 N/8 · 未过 gate 数`
- 点选即切换加载对应 journey.json（仍走"粘贴/选文件"同一条解析管线，不轮询不监听）
- 约束：扫描范围 = 用户显式配置的目录，禁止全盘扫描

### V2-3 CLI --session 暴露（编排侧，不依赖 Gate A）
- 缺口（已实证）：scripts/tt-journey.mjs 内部 updateJourney/readJourney/withJourneyLock/journeyPath 全部已支持 sessionId（L51-52, L72, L124, L127），但 main() CLI 层 L501 只解析 `--workspace`，sessionId 管道断在入口
- 修改：main() 增 `const session = arg('session')`，贯穿 has('update') / has('prereq-check') / 只读渲染三条分支传给 readJourney/updateJourney/journeyPath
- 落点：约 5-8 行改动 + self-test 增 1 条（同 workspace 两个 session 各自独立 journey）
- 回归：regression-all 12/12 保持全绿；tracker 不动
